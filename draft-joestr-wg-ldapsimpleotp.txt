 Lightweight Directory Access Protocol: Simple Authentication with OTP
                  draft-joestr-wg-ldapsimpleotp-latest

Abstract

   This document describes an additional authentication choice for the
   Lightweight Directory Access Protocol (LDAP) which consists of
   credentials in the form of name, password, and a one-time password
   (OTP).

1.  Introduction

   The Lightweight Directory Access Protocol (LDAP) RFC4510 is a
   protocol for accessing directories.  It offers searching, fetching,
   and manipulating directory content and ways to access a set of
   security functions.

   The LDAP also offers to Login, or in LDAP terminology 'Bind
   operation', to a given set of credentials.

   These credentials are represented by the 'AuthenticationChoice'
   defined in RFC4511.

2.  LDAP Bind operation

   The 'Bind operation' (RFC 4511, Section 4.2) (https://www.rfc-
   editor.org/info/rfc4511/#section-4.2) defines the authentication
   choice freely.

   The 'Bind request' is defined as follows:

      BindRequest ::= [APPLICATION 0] SEQUENCE { version INTEGER (1 ..
      127), name LDAPDN, authentication AuthenticationChoice }

3.  Simple Authentication Method with OTP

   The 'Simple Authentication Method with OTP', or short 'Simple OTP',
   is a way to present the LDAP server a password and a one-time
   password (OTP).

   The Authentication scope is defined as:

      AuthenticationChoice ::= CHOICE { simple [0] OCTET STRING, /* 1
      and 2 are reserved */ sasl [3] SaslCredentials, simpleotp [4]
      SimpleOtp, ... }

      SimpleOtp ::= SEQUENCE { password OCTET STRING, onetimepassword
      OCTET STRING }

   Text based passwords and one-time password transferred to the server
   using the 'simpleotp' 'AuthenticationChoice' SHALL be transferred as
   UTF-8 RFC3629 encoded Unicode.
